# 📝 ToDo App – Spring Boot Full Stack Application

A full-stack **Spring Boot MVC ToDo application** built using **JSP, Bootstrap (via dependency), Spring Data JPA, Spring Security, and H2 in-memory database**.  
This project demonstrates how traditional **enterprise Java web applications** are developed using server-side rendering.

---

## 🚀 Tech Stack

### Backend
- Spring Boot
- Spring MVC
- Spring Data JPA (Hibernate)
- Spring Security (Basic Authentication)
- H2 In-Memory Database

### Frontend
- JSP (Java Server Pages)
- JSTL
- Bootstrap 5 (via dependency)
- HTML / CSS

---

## ✨ Features

- User authentication using **Spring Security (basic login)**
- Add, update, delete and view Todos
- Server-side form binding using Spring MVC
- Responsive UI using Bootstrap
- Clean MVC architecture
- In-memory database for fast development and testing

---

## 🗄️ Database

- Uses **H2 in-memory database**
- Integrated with **Spring Data JPA**
- Data resets on application restart
- Ideal for development and learning purposes

---

## 🏗️ Architecture Overview

- **Controller** → Handles HTTP requests
- **Repository (JPA)** → Database operations
- **JSP Views** → UI rendering
- **Bootstrap** → Styling and responsiveness
